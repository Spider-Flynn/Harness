# 1. 意图接入系统

## 一、职责与产出

理解用户以任意方式表达的当前意图，经必要对齐后形成足以指导后续行动的“已对齐用户意图”。

意图可以是任务目标，也可以是设计、执行、流程、约束或授权意图。本系统不按固定字段收集
需求，不规定输入如何获取，也不选择或执行后续能力。

## 二、核心问题

1. 如何从自然表达和已有材料中准确理解用户真正想做什么。
2. 如何只确认会改变后续行动或结果的歧义，而不增加无效确认。
3. 如何保留用户的设计与执行意图，不用项目现状或 AI 偏好替换。

## 三、实现原则

由主会话加载 `intent` 持续与用户对齐。不同形式和来源的内容在进入本系统后都是当前任务输入，
具体获取方式由对应能力负责。

- 先利用当前对话和已有材料还原意图，能自行确定的信息不再询问用户。
- 用户表达足以指导后续时直接继续；不同理解会改变行动或结果时才提出最少问题。
- 问题存在依赖时逐个解决，并在有依据时给出推荐，直到双方形成共同理解。
- 对齐结果按任务复杂度自然表达，只保留会影响后续行动的信息，不使用固定模板。

## 四、协作关系

```text
用户输入或其他能力取得的材料 → intent → 已对齐用户意图 → 按意图选择所需能力
新的或变化的用户意图 → intent 重新对齐 → 重新判断后续行动
```
