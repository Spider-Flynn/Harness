# Rules Know

## 定位

作为 `build` 和 `know` 知识沉淀的只读依赖，提供共享的知识结构、内容、质量和维护规则。
本 Skill 不接管调用方的问答、取材、写入和回读，不作为 HARNESS 或 Router 的独立流程节点。
普通知识检索无需加载本 Skill。

## 读取指引

1. 依据调用方已经确定的建设或沉淀范围，先完整读取 [共同规则](references/共同规则.md)。
2. 只完整读取下表中本次涉及的类型规则；需要组织新内容时再参考该规则链接的模板，不全量加载。
3. 将适用规则和必要模板交回当前 Build 或 Know 工作，不单独生成知识、建立任务文件或执行写入。
   范围不明确或引用缺失时返回具体缺口，不自行扩大范围或启动其他能力。

| 知识对象 | 类型规则 | 默认位置（相对于业务项目 `.harness/know/`） |
|---|---|---|
| 业务画像 | [业务画像](references/业务画像.md) | `业务画像.md` |
| 运行模型 | [运行模型](references/运行模型.md) | `运行模型.md` |
| 功能 | [功能](references/功能.md) | `功能/<业务模块>/<功能>.md`，模块入口为 `README.md` |
| 数据源 | [数据源](references/数据源.md) | `数据源/index.json`，SQL 和数据集保留原生格式 |

返回前确认所引用的规则和模板实际存在、覆盖当前对象，且没有把未涉及类型带入调用方上下文。
规则和模板属于本 Skill 的只读源码；业务项目知识由调用方维护在 `.harness/know/`，不写入本目录。
