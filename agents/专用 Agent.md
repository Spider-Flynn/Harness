# 专用 Agent

> 状态：角色合同已形成，尚未固化为平台原生配置或经过真实任务验证。

专用 Agent 只承载固定 Prompt、职责和权限，不替代 Skill 规则、运行时编排或人工决定。

| Agent | 必要性 | 职责与权限 |
|---|---|---|
| Audit Agent | 必需 | 初步运行时由干净只读 Subagent 加载 `audit`；平台原生配置待权限方案验证 |
| Knowledge Agent | 条件 | 为某个知识建设子能力执行边界明确的只读取证工作包；不跨子能力统一结构或结论，也不直接写入 |
| Router Agent | 待验证 | 只有真实运行证明固定角色能提高路由稳定性时配置；选择仍受 `flows/` 限制 |
| Retro Agent | 待验证 | 只有运行证据和复盘频率足以支持独立角色时配置；只提出改进候选 |

Subagent 是临时上下文分叉，不是专用 Agent。正式审计即使使用 Subagent 运行，也必须另外满足
干净上下文、只读权限和 Audit Agent 职责。当前只实现了角色与 Skill 合同，不能把行为约束
写成已经具有平台级只读硬权限。
